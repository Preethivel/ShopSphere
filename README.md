## 🚀 What is ShopSphere?

ShopSphere is a production-grade multi-vendor e-commerce platform where:
- **Sellers** can list products, manage inventory and fulfil orders
- **Buyers** can search, cart, checkout and track orders in real time
- **Admins** can manage the platform and view analytics

Built to solve real engineering problems — payment failures, inventory overselling, distributed transactions, and AI-powered recommendations.
